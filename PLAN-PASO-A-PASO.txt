  REGLAS DE TRABAJO DEL EQUIPO
================================================================================

1. CONVENCIONES
   - Conventional Commits: feat:, fix:, test:, docs:, chore:
   - Ramas: main (protegida) <- develop <- feature/nombre-tarea
   - Cada tarea = 1 issue en GitHub + 1 Pull Request
   - Ningún PR se mergea sin review del compañero
   - Meta de commits: 45-55% cada uno (verificar con: git shortlog -sn)

2. COMUNICACIÓN
   - Daily async (15 min): mensaje "ayer / hoy / bloqueo" por WhatsApp/Discord
   - Sync semanal (1 h): revisar checklist, repartir semana siguiente
   - Sync mid-week opcional (30 min, miércoles): desbloquear si algo va lento
   - Pair session (2 h/semana mínimo): Keycloak, Docker, observabilidad, CI/CD
   - Si algo lleva >2 días bloqueado: pair session entre Jean y Emilio ese mismo día

3. REGLA DE ORO
   - NO avanzar a la semana N+1 hasta que los entregables de la semana N
     estén hechos, probados y entendidos por AMBOS.

4. REPARTO EQUITATIVO
   - Jean  = Persona A (backend, infra, Keycloak, GHA, requisitos backend)
   - Emilio = Persona B (frontend, staging, Jenkins, guía pruebas, E2E)
   - Cada semana alternan quién abre el PR primero
   - Ambos revisan el PR del otro siempre
